## 🌟 Overview

NCH-Switch-2026 is built around a simple belief: audio should move freely between formats, devices, and ecosystems. Whether you're archiving lectures, remastering old cassette rips, or preparing audio beds for video editing, the toolchain here is designed to feel like a well-organized workshop rather than a maze of dials.

This project tracks the Windows 10 and Windows 11 release line, documenting installation variants, batch processing strategies, and quality presets. The material is written for both casual listeners and audio tinkerers — no prior conversion experience required.

## 🛠️ Quick Start Walkthrough

1. Launch the application after installation completes.
2. Use the **Add Files** button or drag audio files into the main window.
3. Pick an output format from the dropdown (MP3, FLAC, AAC, and others).
4. Select a preset, or open **Advanced Settings** to fine-tune.
5. Choose your destination folder.
6. Press **Convert** and watch the progress bar.
7. Retrieve your converted files — original sources remain untouched.

That's the whole loop. For repeated tasks, save your configuration as a custom preset so future conversions are a two-click affair.

## 📈 Performance Notes

Modern CPUs handle dozens of parallel conversion threads efficiently. The engine detects available cores and distributes work accordingly, preventing the classic "one file at a time" bottleneck. Memory usage stays modest even for multi-hour batches, and disk I/O is sequenced to avoid unnecessary drive thrashing.

For very large libraries (thousands of files), splitting batches into per-album groups often yields smoother progress reporting and easier error isolation.

## ❓ Frequently Asked Questions

**Does this work on Windows 11 ARM devices?**
It runs through emulation layers with acceptable performance, though native ARM builds are on the roadmap.

**Can I convert multiple folders at once?**
Yes. Recursive folder scanning is supported, with an option to preserve subfolder structure in the output.

**Will metadata survive conversion?**
In most cases, yes. ID3, Vorbis comments, and common tag fields are mapped across formats. Edge cases are documented individually.

**Is there a portable mode?**
A portable configuration is described in the docs, allowing use from removable drives without system-level changes.

**Can I cancel mid-batch?**
Yes. The queue supports pausing and stopping, with partial results preserved.
